# Security Policy

## Supported Versions

We actively maintain and provide security patches for the following versions of `TVTMediaPlayer`:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

We take the security of our users and their surveillance systems seriously. If you identify a security vulnerability in `TVTMediaPlayer`, please **do not** report it via a public GitHub issue. Instead, report it privately to the maintainer.

### Where to Report
Please send an email detailing the vulnerability to **[yevhenkhyzhniak@icloud.com]**.

### What to Include
To help us triage and resolve the issue quickly, please include:
1. **Description**: A detailed description of the vulnerability and its potential impact.
2. **Steps to Reproduce**: Detailed steps, code snippets, or configurations to reproduce the vulnerability.
3. **Environment**: Xcode version, CocoaPods version, target iOS versions, and any specific device configurations.
4. **PoC (Proof of Concept)**: If available, attach a minimal code example or scenario displaying the exploit.

---

## Our Response Process

1. **Acknowledgment**: We will acknowledge receipt of your report within **48 hours** and verify the vulnerability.
2. **Investigation**: We will work to investigate the root cause and assess the impact. We may contact you for further details or clarification.
3. **Patching**: We will develop a fix and test it thoroughly to ensure it does not break functionality or backward compatibility.
4. **Release**: We will release a patched version of the CocoaPod and notify you when the issue is resolved.
5. **Credit**: If you wish, we will gladly attribute credit to you for discovering and responsibly reporting the vulnerability in our release notes.

Thank you for helping keep `TVTMediaPlayer` secure!
